# 刘心睿 · 配乐作品集

个人配乐作品集网站。单文件、零依赖，直接用浏览器打开 `index.html` 即可预览。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，仓库名用英文（例如 `portfolio`），可见性选 **Public**。
2. 进入新仓库页面，点 **uploading an existing file**，把本文件夹里的 `index.html` 拖进去，提交。
3. 打开仓库的 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/(root)**，点 Save
4. 等 1～2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 说明

- `index.html` —— 网站本体。背景图、封面图已全部内嵌，不依赖任何外部文件。
- `.nojekyll` —— 告诉 GitHub Pages 不要用 Jekyll 处理，原样发布。
- 视频来自新片场与哔哩哔哩的公开播放器，需要联网才能观看。
